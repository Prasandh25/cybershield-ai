# CyberShield AI

### Explainable AI-Based Cyber Threat Intelligence and Intrusion Detection System

CyberShield AI is an Explainable AI-based Intrusion Detection System designed to detect, classify, explain, and assess network security threats using machine learning.

## Project Objectives

- Detect malicious network traffic using machine learning.
- Classify different types of cyber attacks.
- Provide explainable predictions using XAI techniques.
- Assign threat severity based on detected activity.
- Monitor network traffic through an ESP32-assisted capture architecture.
- Provide security information through a web-based dashboard.
- Generate downloadable security reports.
