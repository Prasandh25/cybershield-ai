# System Requirements

## Functional Requirements

1. Capture network traffic.
2. Preprocess captured traffic.
3. Extract model-compatible features.
4. Detect benign and malicious traffic.
5. Classify attack categories.
6. Explain model predictions.
7. Calculate threat severity.
8. Store detection results.
9. Display alerts through the dashboard.
10. Generate security reports.

## Hardware Requirements

- ESP32 development board
- Development computer
- Wi-Fi network
- USB data cable

## Software Requirements

- Windows
- Python 3.11
- Git
- Arduino IDE
- Node.js
- React
- FastAPI
- SQLite

## Machine Learning Requirements

- CIC-IDS2017 dataset
- Data preprocessing pipeline
- Classification models
- Explainability layer
